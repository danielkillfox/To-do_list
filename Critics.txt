Замечания к tasks.html / script.js (по состоянию на 30.09.2026)
============================================================

1. tasks.html, строки 24-25 — <option> пустые, нет текста.
   value должен быть кодом языка, а не словом:
   <option value="ru">Русский</option>
   <option value="en-US">English (US)</option>
   <option value="en-GB">English (UK)</option>

2. tasks.html, строка 32 — id="Label" с большой буквы.
   В CSS селекторы по id регистрозависимы. Лучше id="label".

3. tasks.html, строка 30 — <form type="dialog"> — атрибут называется method,
   а не type. Сейчас это обычная форма, которая перезагрузит страницу.
   Нужно: <form method="dialog">

4. tasks.html, строки 35-36 — обработчики в JS на кнопки диалога не нужны.
   У кнопок внутри <form method="dialog"> type по умолчанию submit,
   они сами закрывают окно, а значение value становится dialog.returnValue.
   Достаточно читать dialog.returnValue после закрытия.

5. tasks.html, строки 31-34 — у инпутов нет name (нужен для FormData)
   и required (чтобы пустая заметка не закрывала окно).
   Минимум required на text-инпуты.

6. script.js, строки 5-15 — три пустых обработчика. Решить, что доделывать:
   открытие/закрытие dialog или логика переключения языка.
